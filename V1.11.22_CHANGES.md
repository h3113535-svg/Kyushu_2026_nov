# Kyushu_2026_nov v1.11.22 Changes

## Scope
- Fix D1–D9 weekday display only.
- No itinerary date/content changes.
- No Firebase content update.

## Root cause
The trip dates themselves were correct (`2026-11-21` through `2026-11-29`).
The weekday renderer parsed each date as midnight in Japan (`+09:00`) and then called local `getDay()` on a Taiwan device (`+08:00`). That converts Japan midnight to 23:00 on the previous calendar day in Taiwan, shifting every displayed weekday backward by one day.

## Fix
Weekday calculation now treats the ISO date as a timezone-independent calendar date and uses `getUTCDay()`.

Correct sequence:
- D1 11/21 — 週六
- D2 11/22 — 週日
- D3 11/23 — 週一
- D4 11/24 — 週二
- D5 11/25 — 週三
- D6 11/26 — 週四
- D7 11/27 — 週五
- D8 11/28 — 週六
- D9 11/29 — 週日
