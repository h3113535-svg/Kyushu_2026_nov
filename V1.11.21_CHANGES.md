# Kyushu_2026_nov v1.11.21 Changes

## Scope
- Relaxed quick-entry form validation for travel use.
- Preserved owner-only shared deletion behavior.
- No itinerary/content changes.
- No Hero/palette/layout changes.

## What changed
1. Shopping quick-add:
   - Only `商品` is required.
   - `預算`, `店家`, and `預計哪天` are optional.
   - Existing `誰的` selector remains available.
2. Expense quick-add:
   - Only a valid positive `金額` is required.
   - `名稱` and `日期` are optional.
   - Empty expense names are saved as `未命名支出`.
   - Existing payer selector and pre-checked split members remain available.
3. Food quick-add:
   - Only `店名` is required.
   - `區域` and `備註` are optional.
4. Custom booking/ticket quick-add:
   - Only `名稱` is required.
   - `時間／日期`, `處理期限`, `備註`, and `地點` are optional.
5. Optional fields are explicitly labeled `（選填）` where helpful.
6. Preserved the configured owner email in `firebase-config.js` so owner-delete behavior is not reset by this release.
7. Bumped app/cache version from `1.11.20` / `11120` to `1.11.21` / `11121`.

## Firebase
- No itinerary/content change.
- No Firebase Seed re-import needed.
- No Realtime Database data migration needed.
