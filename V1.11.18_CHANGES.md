## Problem fixed
Some UI added in later versions used fixed pixel font sizes after the original `data-font-size="xlarge"` rules. Those later CSS rules overrode the user's maximum-font setting, so certain labels and secondary text stayed small.

## What changed
1. Added a final maximum-font override layer at the end of `style.css`.
2. Covered the later daily-heading UI and the v1.11.17 D1-D9 food accordion.
3. Added missing maximum-font coverage for weather hints, family overview, autumn watch, official-status cards, driving cards, booking/task metadata, tool panels, settings/forms, guide notes, PDF attachment hints, and image-reader controls.
4. Artwork/image contents are not scaled or modified.
5. Bumped version/cache from `1.11.17` / `11117` to `1.11.18` / `11118`.
