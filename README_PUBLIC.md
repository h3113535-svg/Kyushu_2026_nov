# Kyushu 2026 November PWA

Version: **1.10.1**

## 這版重點

- 新增「離線旅行包」：在設定內可手動下載 D1–D9 中／日文主圖、Decision、天氣、紅葉狀態與 Empty State 素材，共 38 項，約 14 MB。
- 離線旅行包採手動下載，不拖慢第一次開 App；已下載後可補齊／更新／移除。
- 延續已授權裝置的私人行程快取：先在線上成功登入並載入過行程，之後無網路時可從本機開啟。
- Service Worker 拆成 Shell / Runtime / Offline Pack 三層快取；App 更新不會刪掉使用者手動下載的離線旅行包。
- 真正移除 10 月專屬的布丁狗／烏薩奇、Secret Life、Buddy 互動與舊 Chapter 引擎。
- 清理歷代 Hero CSS 疊加，v1.10.1 只保留一套和風 Hero 最終規則，降低日後互相覆蓋風險。
- 保留三套 11 月顯示風格：旅冊、海空、和風秋旅；和風秋旅為預設。

## 更新方式

`UPDATE ONLY`：把檔案覆蓋到 `Kyushu_2026_nov` repo 根目錄。另請依 `DELETE_OLD_FILES.txt` 刪除已廢棄檔案，才會讓 GitHub repo 本身也真正變小。

`FULL BACKUP`：完整可部署版本，檔案都位於 ZIP 根目錄。

不需要重新匯入 Firebase 行程資料。
